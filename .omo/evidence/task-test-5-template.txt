## Test Scenarios Covered
1. Single interpolation: `let name = "Ruyi"; print(`Hello ${name}!`);`
2. Multiple interpolations: `let a = 1, b = 2; print(`${a} + ${b} = ${a + b}`);`
3. Pure string (no interpolation): `print(`plain text`);`
4. Empty template: `` print(``); ``
5. String concat in interpolation: `let prefix = "Result: "; let value = 42; print(`${prefix}${value}`);`
