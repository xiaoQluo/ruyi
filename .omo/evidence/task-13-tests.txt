## Test Structure

Each test:
1. Parses a Klang program with pattern matching
2. Runs the type checker
3. Verifies no errors (or expected warnings)

## Integration with TypeChecker

Tests use the same check_program() helper as other type checker tests:
- Parses source with Parser::new()
- Checks for lexer/parse errors
- Runs TypeChecker::check()
- Asserts no errors (or checks for expected warnings)
