Codegen Changes Summary
-----------------------
1. compile_try (stmt.rs:678-887)
   - Creates a landing-pad basic block (`try_lpad`) when catch or finally is present
   - Builds a `landingpad` instruction with:
     - Personality function: `__gxx_personality_v0`
     - Catch clause: `i8* null` (catches all exceptions)
     - Cleanup flag: `true` when finally is present
   - Extracts exception pointer from landing pad and stores it in `exc_ptr`
   - Branches to catch_bb, finally_bb, or merge_bb

2. compile_throw (stmt.rs:607-672)
   - When inside a try context with a landing pad:
     - Uses `build_invoke` instead of `build_call` for `ruyi_throw`
     - Normal destination: `throw_unreachable` block (contains `unreachable`)
     - Unwind destination: `try_lpad` block
   - Falls back to original manual branch logic when no landing pad exists

Expected LLVM IR Output (conceptual)
------------------------------------
define void @main() {
entry:
  ...
  invoke void @ruyi_throw(i8* %exc_ptr)
          to label %throw_unreachable unwind label %try_lpad

throw_unreachable:
  unreachable

try_lpad:
  %lpad = landingpad { i8*, i32 }
          catch i8* null
          cleanup
  %exc_val = extractvalue { i8*, i32 } %lpad, 0
  store i8* %exc_val, i8** %exc_ptr
  br label %try_catch
  ...
}

Verification
------------
- Invoke instruction is emitted by compile_throw when throwing inside a try region
- Landing pad is generated by compile_try to catch unwinding exceptions
- IR will contain both `invoke` and `landingpad` instructions for try/catch/finally

Note: Full `ruyic --emit-llvm` verification is blocked in this environment because
LLVM 14 is not installed (llvm-sys requires LLVM_SYS_140_PREFIX). The codegen source
changes are verified by code review and use the same inkwell APIs already exercised
in the ruyi_runtime inkwell tests.
