# Task 10: Support impl Trait for Built-in Types (string/int/float/bool)

## Implementation Summary

### Problem
`impl Printable for string { ... }` was not being recognized because:
1. `type_annotation_name()` only handled `TypeAnnotation::Identifier` and `TypeAnnotation::Generic`
2. `implements()` only checked `Type::Named` and `Type::Generic`, not primitive types

### Solution

#### 1. AST Change (parser/ast.rs)
Added `Builtin(String)` variant to distinguish built-in type identifiers:
```rust
pub enum TypeAnnotation {
    Identifier(String),
    Builtin(String), // string, int, float, bool, etc.
    ...
}
```

#### 2. Parser Change (parser/parser.rs)
Added `is_builtin_type()` helper and updated parsing:
```rust
fn is_builtin_type(name: &str) -> bool {
    matches!(name, "string" | "int" | "float" | "bool")
}

Some(Token::Ident(name)) => {
    ...
    if Self::is_builtin_type(&name) {
        Ok(TypeAnnotation::Builtin(name))
    } else {
        Ok(TypeAnnotation::Identifier(name))
    }
}
```

#### 3. type_annotation_name() Update (traits.rs)
Now handles `TypeAnnotation::Builtin`:
```rust
fn type_annotation_name(annotation: &TypeAnnotation) -> String {
    match annotation {
        TypeAnnotation::Identifier(name) => name.clone(),
        TypeAnnotation::Builtin(name) => name.clone(),
        TypeAnnotation::Generic { base, .. } => base.clone(),
        _ => String::new(),
    }
}
```

#### 4. implements() and get_impl_index() Update (traits.rs)
Extended to check built-in types:
```rust
Type::String | Type::Int | Type::Float | Type::Bool => self
    .type_trait_impls
    .contains_key(&(ty.to_string(), trait_name.to_string())),
```

#### 5. from_annotation() Update (types.rs)
Added handling for Builtin variant:
```rust
crate::parser::ast::TypeAnnotation::Builtin(name) => match name.as_str() {
    "int" => Type::Int,
    "float" => Type::Float,
    "bool" => Type::Bool,
    "string" => Type::String,
    _ => Type::Named(name.clone()),
},
```
