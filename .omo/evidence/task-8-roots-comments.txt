gc/roots.rs docstrings: All are necessary public API documentation. RootSet is a core component of the generational GC with public methods that will be called by generated code and runtime users. Safety docstrings are mandatory for the four unsafe functions (`add_stack_root`, `remove_stack_root`, `add_global_root`, `remove_global_root`). The struct-level docstring explains the purpose and distinction between stack and global roots.
