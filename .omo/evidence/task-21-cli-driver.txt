CLI ARGUMENTS IMPLEMENTED
========================

Input file:
  klangc file.kl

Output file:
  -o output

Optimization level:
  -O0, -O1, -O2

Target triple:
  --target <triple>

Emit options:
  --emit-llvm      Output LLVM IR (.ll file)
  --emit-ast       Output AST (for debugging)
  --emit-typed-ast Output typed AST
  --check          Parse and type check only (no codegen)

COMPILE PIPELINE
================

Source file → Lexer → Tokens
Tokens → Parser → AST
AST → Macro Expansion → Expanded AST
Expanded AST → Type Checker → Typed AST
Typed AST → Code Generator → LLVM IR
LLVM IR → Linker → Native binary

MODULE RESOLUTION
=================

Import statements resolved from:
- Current directory (relative paths)

ERROR HANDLING
==============

All compilation phases collect errors:
- Lexer errors with line/column
- Parser errors with line/column
- Macro expansion errors
- Type checker diagnostics (formatted)
- Codegen errors
- Linker errors

Exit codes:
- 0: Success
- 1: Compilation error
