Notes
-----
- The `#[cfg_attr(test, link(name = "c++abi"))]` attribute ensures test binaries link against the system C++ ABI library on macOS.
- `_Unwind_RaiseException` is declared with `*mut std::ffi::c_void` to avoid `improper_ctypes` warnings from the `String` field inside `UnwindException` (only used behind a pointer).
- `ruyi_begin_catch` calls `__cxa_begin_catch` for ABI compliance but manually computes the payload pointer via `&mut (*unwind_exc).payload` since we allocate `UnwindException` directly rather than using `__cxa_allocate_exception`.
