## Key Design Decisions
1. **Gradual typing**: Unannotated variables default to `dyn`, annotated variables use static checking
2. **Bidirectional inference**: Synthesize mode determines types, check mode verifies against expected types
3. **Type narrowing**: After `x !== null` checks, `x` is narrowed from `T?` to `T` in the true branch
4. **Subtyping**: int <: float, T <: T?, Never <: T, dyn ~ T (consistency), structural object subtyping, contravariant function params
5. **Constraint solving**: Unification-based with occurs check for generic inference
6. **Error recovery**: Type::Error prevents cascading errors
7. **Cast insertion**: When dyn flows into static context, DynCast warning is emitted
