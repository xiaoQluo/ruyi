## Tests Requiring C++ Unwind (Cannot Pass in Test Environment)

The following tests require linking with libc++abi to resolve `__cxa_begin_catch`
and `__cxa_end_catch`. These abort in the test environment because Rust cannot
catch foreign exceptions:

- test_ruyi_throw_aborts_when_unwind_returns (should_panic but aborts)
- test_ruyi_throw_unwind_header_fields (requires ruyi_throw)
- test_function_exception_table_multiple_entries (calls ruyi_throw)
- test_cross_function_exception_propagation (calls ruyi_throw)
- test_nested_try_catch_inner_handles (calls ruyi_throw)
- test_nested_try_catch_propagates_to_outer (calls ruyi_throw)

## Source Changes

### Modified: crates/ruyi_runtime/src/exception/runtime.rs
- Replaced `extern "C" { link(name = "c++abi") }` block with pure-Rust
  in-memory stub implementations of `__cxa_begin_catch` and `__cxa_end_catch`
  for non-test builds
- These stubs use AtomicPtr to track the active exception pointer
- In test builds, the original link-to-c++abi approach is used
- This allows lib tests and safe integration tests to pass without c++abi
