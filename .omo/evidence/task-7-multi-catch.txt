# Task 7: Multi-Catch Support - Evidence

## Date: 2026-05-04

## Changes Made

### 1. AST Change (crates/ruyic/src/parser/ast.rs:139)
Changed `catch: Option<CatchClause>` to `catch: Vec<CatchClause>`.

### 2. Parser Change (crates/ruyic/src/parser/parser.rs:983-1005)
Changed `if self.match_token(&Token::Catch)` to `while self.match_token(&Token::Catch)` to collect multiple catch clauses into a Vec.

### 3. Codegen Change (crates/ruyic/src/codegen/stmt.rs:61-65, 683-888)
- Changed `compile_try` signature from `Option<&CatchClause>` to `&[CatchClause]`
- Changed `catch_bb` creation from `.map()` to `if !catch.is_empty()`
- Changed landing pad condition from `.is_some()` to `!catch.is_empty()`
- Changed `catch.is_none()` to `catch.is_empty()`
- Changed single `if let Some(catch_clause)` to `for catch_clause in catch` loop

### 4. Typechecker Change (crates/ruyic/src/typechecker/inference.rs:556-571)
Changed `if let Some(catch_clause) = catch` to `for catch_clause in catch` loop.

### 5. Macro Expand Change (crates/ruyic/src/macro_expand/expand.rs:148-160)
Changed `catch.as_ref().map(...).transpose()?` to `catch.iter().map(...).collect()`.

### 6. Async Codegen Change (crates/ruyic/src/codegen/async_codegen.rs:65-67)
Changed `catch.as_ref().map(|c| count_awaits_in_statements(&c.body)).unwrap_or(0)` to `catch.iter().map(|c| count_awaits_in_statements(&c.body)).sum()`.

### 7. Tests Update (crates/ruyic/tests/parser.rs:776-836)
- Changed `assert!(catch.is_some())` to `assert!(!catch.is_empty())`
- Changed `catch.unwrap()` to `&catch[0]`
- Changed `assert_eq!(catch, None)` to `assert!(catch.is_empty())`

## Backward Compatibility
- Single-catch syntax `try { } catch { }` still works
- Multi-catch syntax `try { } catch (e) { } catch (e2) { }` now works
- Empty catch Vec `try { } finally { }` is represented as empty Vec instead of None
