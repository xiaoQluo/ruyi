Task 16: Async/Await with Green Thread Runtime - Type Checker Evidence
=====================================================================

1. Future Type Added
   - File: crates/klangc/src/typechecker/types.rs
   - Added `Future(Box<Type>)` variant to the `Type` enum
   - Updated `Display` impl to show `Future<T>`
   - Updated `from_annotation` to recognize `Future<T>` generic type

2. Async Function Type Inference
   - File: crates/klangc/src/typechecker/inference.rs
   - `Declaration::Function` now wraps return type in `Future<T>` when `is_async` is true
   - `Declaration::ClassElement::Method` similarly wraps async method returns
   - `Expr::ArrowFunction` wraps return type in `Future<T>` when `is_async` is true
   - `Expr::Function` wraps return type in `Future<T>` when `is_async` is true

3. Await Expression Type Inference
   - `Expr::Await` unwraps `Future<T>` to `T`
   - `UnaryOp::Await` similarly unwraps `Future<T>` to `T`
   - Both emit a type mismatch error when the operand is not a Future

4. Tests Added (crates/klangc/tests/typechecker.rs)
   - test_check_async_function_declaration
   - test_check_async_function_type
   - test_check_async_arrow_function
   - test_check_await_expression
   - test_check_await_on_non_future_error
   - test_check_async_method
   - test_future_type_display
   - test_future_subtype
   - test_check_nested_async
