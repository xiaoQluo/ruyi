# Draft: v0.5 Development Plan

## Requirements (confirmed)
- **范围**: 混合 — 标准库扩展 + 关键 codegen 补充
- **测试策略**: TDD + Agent QA
- **优先级**: 全部平级推进 (math/time/json/random/fmt/regex/test/collections)
- **约束**: 禁止修改解析器、类型检查器、宏展开器、词法分析器

## Technical Decisions
- **测试模式**: 沿用 `tests/integration/cases/{category}/{test}.ry` + `{test}.expected` 模式
- **模块模式**: 沿用 `core.ry` 的 `module TypeName { fn method(self: Type): ReturnType }` 模式
- **内建函数**: 使用 `__builtin_*` 命名模式
- **Math 实现**: 需要新增 LLVM intrinsic 调用或运行时函数 (当前无 math 内建函数)

## Research Findings
- **builtins.rs**: 17 个内建函数，无 math 函数 (sin/cos/sqrt 等)
- **String concat**: `string + string` 支持，`string + int` 不支持
- **SetIterator**: next() 总是返回 None — 需要修复
- **现有 stdlib**: 9 个模块 (core, string, io, error, option, result, process, path, collections)
- **缺失 stdlib**: math, time, json, random, fmt, regex, test, buffer, net
- **集成测试**: 45 个 .ry 测试文件, 使用 .expected/.error 模式

## Open Questions
- Math 函数: 用 LLVM intrinsic 还是运行时函数? 需要新增 builtins
- String + int: 是 codegen 层面的关键缺口
- 哪些 codegen 缺口必须补? (string concat with int, for loop, try/catch, match?)

## Scope Boundaries
- INCLUDE: 标准库 .ry 模块 + 必需内建函数 + 集成测试
- EXCLUDE: 解析器/类型检查器/宏展开器/词法分析器修改
- UNCLEAR: 哪些 codegen 缺口需要在此版本修复
