- 所有导出成员均使用 JSDoc 风格的注释块，包含 @author, @date, @param, @return 等标签。
- 原生绑定函数统一采用双下划线前缀命名规范（如 `__builtin_array_length`, `__io_read_line`），以区分用户级 API 与运行时内部实现。
- 类方法中涉及实例操作时，显式声明 `self` 参数并指定类型（如 `fn toString(self: string): string`），以明确方法接收者。
- 对于可能失败的操作，优先提供返回 `Option` 或 `Result` 的安全版本，同时保留可能抛异常的 `unwrap` 等便捷方法。
