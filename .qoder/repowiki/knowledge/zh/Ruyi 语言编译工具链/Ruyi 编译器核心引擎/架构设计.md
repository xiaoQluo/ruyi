- **流水线编排**：由 `driver.rs` 定义标准编译管线（Lexer → Parser → Macro Expand → Type Check → Code Gen），各阶段通过共享的 AST 结构体进行数据传递。
- **模块解析与合并**：内置 `ModuleResolver` 处理 `import` 语句，支持基于 `RUYI_HOME` 和相对路径的依赖查找，并将多文件 AST 扁平化合并为单一程序单元供后续阶段处理。
- **统一错误抽象**：定义 `CompileError` 枚举，通过 `From` trait 自动转换各子模块（如 `ParseError`, `MacroError`）的特有错误，实现跨阶段的错误聚合与渲染。
- **运行时集成**：在代码生成前通过 `cargo build` 自动触发 `ruyi_runtime` 的构建，确保生成的 LLVM IR 能正确链接底层内存管理与异常处理库。
